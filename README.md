# Smart Air Purifier

A Raspberry Pi-based IoT system for monitoring and purifying indoor air. It uses sensors to detect PM2.5, temperature, and humidity, activating a fan when pollution is detected. Real-time data is visualized on the Blynk app.

## Features

- PM2.5 detection using SDS011
- DHT11 for temperature & humidity
- Fan control based on pollution levels
- Live data monitoring on Blynk (IoT)
- Expandable for AI-based predictions

## Tech Stack

- Raspberry Pi 5
- Python 3
- Blynk IoT
- Sensors: SDS011, DHT11, MQ135 (optional)
- GPIO, UART, I2C
